# T6 — Executar e refatorar `ecommerce-api-legacy`

## Objetivo

Demonstrar portabilidade da skill em uma API Node.js/Express de LMS com fluxo de checkout.

## Atividades

1. Copiar/conferir a skill no projeto 2 e executar a Fase 1.
2. Validar stack, domínio, arquivos, rotas e fluxo de checkout identificados.
3. Executar a Fase 2, conferir achados contra a análise manual e salvar `reports/audit-project-2.md` na raiz.
4. Confirmar mínimo de cinco findings e ao menos um CRITICAL ou HIGH, com evidência e severidade justificadas.
5. Após revisar o relatório, confirmar explicitamente a Fase 3.
6. Refatorar para responsabilidades MVC adequadas ao Express, preservando contratos e fluxo de checkout.
7. Validar boot e endpoints originais; registrar comandos e resultados.
8. Atualizar `docs/ecommerce-api-legacy/README.md` com o relatório, resumo antes/depois, mudanças realizadas, comandos e evidências reais de validação, além de limitações conhecidas.
9. Preparar e registrar o commit do código refatorado do projeto 2 no fork.

## Critérios de aceite

- Stack Node.js/Express e domínio LMS/checkout detectados corretamente.
- A skill executa as três fases sem instruções específicas de Flask.
- O relatório existe no caminho exigido e tem pelo menos cinco findings.
- A aplicação inicia e os endpoints originais continuam respondendo.
- O README do projeto em `docs/` registra os resultados sem declarar validações não executadas.
- A organização final melhora separação de responsabilidades sem alterar indevidamente o fluxo público.
- O código refatorado está commitado no repositório de entrega.

## Checklist de conclusão

- [x] Skill foi copiada/conferida e Fase 1 identificou stack, domínio e checkout.
- [x] Relatório da Fase 2 foi salvo em `reports/audit-project-2.md` e comparado à análise manual.
- [x] Confirmação explícita foi obtida antes de iniciar a Fase 3.
- [x] Refatoração preservou o fluxo de checkout e os contratos públicos.
- [x] Boot e endpoints originais foram validados com evidência registrada.
- [x] `docs/ecommerce-api-legacy/README.md` foi atualizado com resultados e limitações.
- [ ] Código refatorado foi commitado no repositório de entrega.
