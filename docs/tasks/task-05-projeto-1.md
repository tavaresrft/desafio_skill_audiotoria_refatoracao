# T5 — Executar e refatorar `code-smells-project`

## Objetivo

Aplicar a skill ao projeto Flask de e-commerce, validar a primeira execução e registrar os artefatos exigidos.

## Atividades

1. Executar a Fase 1 e conferir stack, domínio, arquivos analisados, arquitetura e persistência.
2. Executar a Fase 2; comparar os achados com a análise manual e salvar o relatório em `reports/audit-project-1.md` na raiz.
3. Confirmar que há pelo menos cinco findings, incluindo pelo menos um CRITICAL ou HIGH, com severidade e linhas verificáveis.
4. Revisar o relatório e fornecer confirmação explícita para iniciar a Fase 3.
5. Refatorar preservando endpoints e comportamento, criando configuração, camadas MVC adequadas, tratamento de erros e entry point claro.
6. Validar inicialização e endpoints originais; registrar comandos e resultados.
7. Atualizar `docs/code-smells-project/README.md` com o relatório, resumo antes/depois, mudanças realizadas, comandos e evidências reais de validação, além de limitações conhecidas.
8. Preparar e registrar o commit do código refatorado do projeto 1 no fork.

## Critérios de aceite

- Stack Python/Flask e domínio de e-commerce detectados corretamente.
- Relatório salvo no caminho requerido e contém no mínimo cinco findings.
- Nenhum arquivo foi modificado antes da confirmação da Fase 2.
- A aplicação inicia e os endpoints originais respondem após a refatoração.
- O README do projeto em `docs/` registra os resultados sem declarar validações não executadas.
- Estrutura MVC, configuração externa, abstração de dados e error handling estão presentes de forma coerente.
- O código refatorado está commitado no repositório de entrega.

## Checklist de conclusão

- [x] Fase 1 identificou corretamente stack, domínio e arquitetura.
- [x] Relatório da Fase 2 foi salvo em `reports/audit-project-1.md` e comparado à análise manual.
- [x] Confirmação explícita foi obtida antes de iniciar a Fase 3.
- [x] Refatoração preservou contratos e aplicou mudanças arquiteturais justificadas.
- [x] Boot e endpoints originais foram validados com evidência registrada.
- [x] `docs/code-smells-project/README.md` foi atualizado com resultados e limitações.
- [x] Código refatorado foi commitado no repositório de entrega.
